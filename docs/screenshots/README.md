# 界面截图

把截图放进这个目录，按下面的文件名命名，README 顶部的图片块就能直接显示。

| 文件名 | 拍什么 | 建议内容 |
|---|---|---|
| 01-records.png | 我的记录 | 四张概览卡 + 随访提醒条 + 记录表格 |
| 02-form.png | 新增检查 | 选图区（含「保留报告照片」勾选）、精读开关 |
| 03-review.png | 校对弹窗 | 匹配项 / 未匹配项 / 两次不一致标签 |
| 04-trend.png | 趋势分析 | 一条有多段的参考带，能看出区间变过 |
| 05-agent.png | 记录详情 · AI 解读 | 正常回答 + 工具调用标签；或越界问题的三段式提示 |
| 06-debug.png | Agent 调试页 | 展开一行，能看到工具名、参数、耗时 |

要求：

- 宽度 1440 左右，PNG，单张不超过 500KB（可用 tinypng 压）
- **只用 demo 数据**，不要出现真实姓名、医院、门诊号
- 截图前把浏览器缩放到 100%，窗口尽量宽一点，避免文字换行
