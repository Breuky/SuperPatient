# 抽取评测

## 目录

| 路径 | 内容 | 是否入库 |
|---|---|---|
| samples/ | 化验单截图 | 否（含个人健康信息） |
| labels/ | 人工标注（CSV） | 否 |
| raw*/ | 每次抽取的原始结果 | 否 |
| run_eval.py | 比对并出报告 | 是 |
| make_draft.py | 从抽取结果生成标注草稿 | 是 |
| extract_all.py | 批量跑抽取 | 是 |
| report.md | 最近一次评测结果 | 否 |

## 流程

1. **生成草稿**（已做过，改了抽取逻辑后可重跑）

   python eval/make_draft.py

2. **人工校对**：打开 labels/0X.csv，对照 samples/0X.jpg 修改

   - name：报告上的原始写法，不要改成指标库的规范名
   - value：报告上的数值或文本
   - unit：报告上的单位
   - refMin / refMax：报告上印的参考区间，没有就留空
   - 模型漏掉的行要手工补；不是测量项的行（分组标题）删掉

3. **重新抽取**（改了 prompt / 别名 / 指标库之后才需要）

   python eval/extract_all.py --out raw3

4. **跑评测**

   python eval/run_eval.py --raw raw3

   结果同时写入 report.md。

## 指标含义

- 召回率：标注里有、且被抽到的行 / 标注总行数。**漏抽会让它掉**。
- 数值准确率：抽到且数值一致（容差 0.5%）/ 抽到的行
- 单位准确率：单位一致（忽略大小写与书写差异）/ 抽到的行
- 归一化率：成功归到指标库的行 / 抽到的行。**掉这里说明别名或指标库不全**
- 误报：抽到了但标注里没有的行，反映幻觉
